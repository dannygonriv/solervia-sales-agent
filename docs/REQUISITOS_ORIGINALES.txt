* Sitios web.
* Aplicaciones web.
* Sistemas administrativos.
* Sistemas internos.
* Automatizaciones.

* Soluciones digitales para PyMEs.

El mercado inicial es Guadalajara, Jalisco, México.

Posteriormente, el sistema deberá permitir buscar prospectos en otras ciudades.

3. OBJETIVO PRINCIPAL

Construir un sistema inteligente de prospección comercial que pueda:

1. Encontrar empresas potencialmente interesadas en los servicios de Solervia.
2. Investigar información pública de esas empresas.
3. Registrar los prospectos en una base de datos.
4. Identificar oportunidades comerciales.
5. Calificar y priorizar prospectos.
6. Preparar correos personalizados.
7. Gestionar campañas comerciales.
8. Realizar llamadas mediante un agente de IA cuando exista una base válida para contactar al destinatario.
9. Mantener conversaciones naturales.
10. Responder preguntas y objeciones comerciales.
11. Intentar concretar reuniones.
12. Registrar resultados.
13. Generar transcripciones y resúmenes.
14. Programar seguimientos.
15. Enviar notificaciones mediante Telegram.
16. Mostrar estadísticas comerciales.
17. Ejecutar tareas programadas desde un servidor.

El sistema debe reducir considerablemente mi trabajo manual de prospección.

Sin embargo, debe respetar las restricciones legales, las preferencias de contacto y los límites configurados por el administrador.
